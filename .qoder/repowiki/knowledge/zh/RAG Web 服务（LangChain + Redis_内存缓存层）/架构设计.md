模块由三个核心文件构成清晰的分层：
- `app.py`：FastAPI 入口，暴露 `/upload`、`/ask`、`/cache/stats`、`/cache/clear`、`/health`、`/` 六个接口；按问题语种路由到对应 Chroma collection，并通过懒加载+双检锁维护 `_stores` / `_retrievers` / `_chains` 单例。
- `rag_langchain.py`：RAG 管道实现——文档加载、按 token 切块、HuggingFaceEmbeddings（子类 `CachedHuggingFaceEmbeddings` 包装向量缓存）、Chroma 检索、cross-encoder 精排、LCEL 链调用 DeepSeek；提供带缓存的 `query()` 入口和 `invalidate_caches()` 失效钩子。
- `cache.py`：独立缓存层，定义 `_MemoryBackend` 与 `_RedisBackend` 两个后端，通过 `_get_backend()` 按 `CACHE_BACKEND`（auto/redis/memory）选择并双检锁初始化；提供 QA/embedding/rerank 三类业务封装、版本号 `bump_version()` 失效机制与命中统计。

依赖方向单向：`app.py` → `rag_langchain.py` → `cache.py`；`cache.py` 不反向依赖上层。中英双库通过 `LANG_MODELS` / `LANG_COLLECTIONS` 隔离，避免不同 embedding 空间的向量混用。可选语义缓存 `SemanticCache` 默认关闭，阈值可配置。
