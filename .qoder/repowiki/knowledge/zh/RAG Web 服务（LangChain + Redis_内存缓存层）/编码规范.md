- 全局对象（embedding 模型、chromadb client、tokenizers、retriever、chain）统一采用「无锁快路径 + with lock 双检」模式懒加载，避免首次并发请求重复构造昂贵资源。
- 所有缓存读写操作包裹 try/except 并在异常时返回 None 或忽略错误，保证缓存层 fail-open——缓存故障只导致变慢，不会让主流程抛错或给出错误答案。
- 缓存 key 统一通过 `hashlib.sha256(...).hexdigest()[:32]` 生成短摘要，并按 `rag:v{版本}:{类型}:{摘要}` 命名，使知识库变更时仅提升版本号即可整体失效。
- 中英文语料严格隔离：embedding 模型、collection 名、tokenizer、semantic cache 均按 `lang` 键分桶，禁止跨语言共享任何向量空间。
- 环境变量驱动配置（`CACHE_BACKEND`、`CACHE_*_TTL`、`CHUNK_TOKENS`、`SEMANTIC_CACHE` 等），通过 `os.getenv` 读取并提供合理默认值，便于 A/B 对比与部署切换。
