# 三体 EPUB 评测档案

**本轮已完成，结项日期为2026-11-06。正式评测范围是第一册。**

总入口为 [可点击图文报告](FINAL_EVALUATION.html)，提供流程图、实验变量、参数、结果表及表头说明。图中节点可直接打开题目与术语；全部40题在同一文件内，无外部页面或网络依赖。保留题严格通过15/16；该通过率仅适用于本题库和自动评分，不代表任意小说问题准确率。

| 档案 | 用途 |
|---|---|
| [可点击图文报告](FINAL_EVALUATION.html) / [Markdown版](FINAL_EVALUATION.md) | 方法对比、参数、结果及可点击流程图；推荐阅读入口 |

其他报告记录各阶段当时的状态，文中“尚未运行”或“下一阶段”等表述属于历史阶段说明，当前完成状态以最终报告为准。完整原始回答、片段和评分位于本地 `raw/` 忽略目录。

全集仅完成语料和索引准备，未执行规模评测；属于独立可选扩展，不影响本轮结项。已完成的保留题不重复生成以选择更好结果。

图文报告可直接在浏览器打开。仓库网页的HTML预览可能只显示源码，此时下载HTML文件后打开，或使用Markdown版及其中的文字链接。离线重建入口为 `eval/threebody/render_readable_report.py`，使用既有RAG Python环境；需要本地 `raw/` 摘要和固定题库，只生成文档，不重新检索、生成或评分。
